Independent concept proposal · 25 September 2026

Ezzy Home, as a launchpad.

“North Star” makes discovery feel immediate and optimistic, while moving booking logistics into one calm, accountable Activity space.

✦ Browse first. Decide with confidence. Track without clutter.

Direction

A warm utility marketplace. Home is for possibility: a clear search doorway, high-recognition divisions, then a small amount of relevant inspiration. It is not a status dashboard.

Navigation shift

On phones, Activity replaces Bookings as the broader place for upcoming services, actions needed, completed history and booking summaries. Payments remains a focused utility.

Design system

Quiet neutral canvas; expressive violet used only to orient and invite action; soft green signals readiness. Cards are shallow and roomy, so the real logos—not UI chrome—carry category recognition.

Accessible by default

Every category is a labelled button, not a logo-only control. The design leaves 44px+ touch space, uses text alongside status colour, and keeps titles / key actions high contrast.

Category data contract

Icons are content, not a shipped enum. Home receives ordered division data from the same future-managed source Command will use. The UI only needs an image URL plus accessible naming.

{ id: "ezzy-well", name: "EzzyWell", iconUrl: "…/well.png", alt: "EzzyWell", sortOrder: 2, isActive: true }

Missing or changed icon

A neutral initial/arrow tile appears when iconUrl is absent or fails. The category remains tappable and correctly named—important for EzzyRide today and any admin change tomorrow.

Intentional restraint

No speculative location map, promotion carousel, or personalisation claim is required for the first release. “Near you” should appear only when location/area and inventory make it honest; otherwise it becomes “Popular now.”
