### B2 — Pure search, shortcode filter and default sort  ✅ DONE (2026-09-12)

- `bookingMatchesSearch(b, query)`: trims and lowercases the query; empty matches everything. It matches a **substring** of `bookerName`, `bookerEmail`, `bookerPhone`, `offeringCode` and `offeringName`, and the booking `id` **by prefix only** (see below).
  - ⚠️ **Reference = PREFIX, ≥4 characters** (review 2026-09-12). A substring match on a UUID is noise: every id is hex plus hyphens, so "12", "ed", "bad" or "cafe" would match most bookings and bury the real results. That is the same rule and the same `MIN_IDENTIFIER` as kiosk close-out (`lib/kioskCloseOut.ts:41,65`), and a reference pasted from the email (the whole UUID) still matches.
  - ⚠️ **Digits-only phone matching only for phone-shaped queries** (review 2026-09-12): only when the query contains nothing but phone characters (`[\d+()\-. ]`, the set `stripPhoneInput` allows at `lib/kioskSteps.ts:136-141`) **and** has ≥4 digits. Otherwise "Unit 5" becomes "5" and matches every phone containing a 5.
  - When it applies, phone is matched **digits-only**, reusing `digitsOnly` from `lib/kioskCloseOut.ts`, so that "917 555" finds both "+63 917 555 0142" and "0917-555-0142". ⚠️ A local `0917…` query will **not** substring-match a stored `+63 917…` (the `0` replaces `63`; see `samePhone` at `kioskCloseOut.ts:78-99`). When the query has ≥10 digits, use that last-10-digit comparison. `samePhone` is currently module-private, so **export it** rather than copy it, and cover the case in the test. The haystack mirrors Transactions (`useTransactionsPage.ts:127`) so the two search boxes behave the same, plus the reference.
  - First/last/full name: the data holds only `full_name` (from the `get_booker_contacts` RPC). A substring match on it covers first, last and full name. There are no separate first/last fields to add.
- ⚠️ **`lib/` import convention:** `node --test --experimental-strip-types` cannot resolve `@/` aliases. The new `lib/bookingSearch.ts` must import with relative `.ts` paths (`import type { Booking } from "./types.ts"`, `from "./kioskCloseOut.ts"`), as `lib/bookingCounts.ts:17` and `lib/kioskSteps.ts:1-2` do.
